• Русский и английский Lang.dat в SolUtilities синхронизированы с исходниками. Подключены настройки очистки временных списков и ресурсов.

English

• Supports the 6 October (6AC53B97) and 26 October (6ADF851C) Rangers.exe builds. Both use the same DLLs. SolHook selects the correct table automatically.
• The 6 October table now includes addresses, signatures, verified hook assumptions, and function fingerprints. Both tables were checked against their corresponding executables.
• Expanded preflight checks for hook groups, including groups with dynamically resolved addresses.
• The Solar profiler was checked on both builds, including all 96 TStar.NextDay probe sites.
• The Russian and English SolUtilities Lang.dat files now include the temporary-list and resource cleanup settings from their sources.

Installation: extract the archive into the game folder. Use your existing Rangers.exe from either supported build. Integration tests were run offline.
