Установка: распаковать в папку Space Rangers HD с заменой файлов.
Rangers.exe в комплект не входит. Основной проверяемый билд: 2026-10-26, TDS 6ADF851C.
В SolUtilities есть таблицы 6ADF851C, 6AC53B97 и устаревшая 6A7AFC5C;
наличие таблицы не означает проверку актуальных функций на старом билде.
Загрузчик XenoNative включён. Сохраните собственный XenoNative.ini перед заменой.

Архивы собраны из установленных файлов, без перекомпиляции и запуска игры.
MANIFEST_SHA256.json содержит SHA-256 каждого включённого файла.
